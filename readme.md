**hcm-ideology-museum** — an interactive web museum presenting Ho Chi Minh's ideology and the path to national independence. Built with **React**, **Vite**, **Tailwind CSS** and **Framer Motion**.

## ✨ Features

- Interactive museum-style exploration of Ho Chi Minh's ideology
- Topics: national independence, socialism, and the revolutionary path
- Smooth animated transitions (Framer Motion)
- Modern, responsive UI with Tailwind CSS
- Deployed live on Vercel

## 🚀 Live Demo

👉 [hcm-202-tau.vercel.app](https://hcm-202-tau.vercel.app)

## 🛠 Tech Stack

- **Framework:** React 18
- **Build tool:** Vite 5
- **Styling:** Tailwind CSS 3, Autoprefixer, PostCSS
- **Animation:** Framer Motion, Lucide icons

## ▶️ Run Locally

```bash
npm install
npm run dev
```

```bash
npm run build    # production build
npm run preview  # preview production build
```
